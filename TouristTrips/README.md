# TouristTrips — учёт туристических поездок (Qt)

## Что делает программа
Графическое приложение на **Qt** (Qt Widgets, qmake) для ведения списка туристических поездок:

- поездка описывается структурой `Trip`: **стоимость, название, дата, изображение**;
- данные отображаются в таблице (`QTableWidget`) и списке (`QListWidget`), у поездок показываются фотографии;
- загрузка поездок из файла (`data/trips.txt` — пример данных с фото Парижа, Лондона и Берлина), добавление и удаление записей;
- **сортировка таблицы быстрой сортировкой (Хоара)**, реализованной вручную (`quicksort.h`), по выбранному столбцу: стоимость, название или дата;
- сортировка списка: стандартная (`std::sort`, по возрастанию и убыванию) и собственная быстрая сортировка;
- контекстные меню таблицы и списка.

Папка `TestQuickSort` — отдельный тестовый проект на QtTest, проверяющий реализацию быстрой сортировки.

## Файлы
- `main.cpp` — точка входа.
- `mainwindow.h/.cpp/.ui` — главное окно (таблица, список, кнопки, меню).
- `trip.h` — структура поездки.
- `quicksort.h` — собственная реализация быстрой сортировки.
- `TouristTrips.pro` — файл проекта qmake.
- `data/` — пример файла данных и изображений.
- `TestQuickSort/` — юнит-тесты сортировки (QtTest).

## Сборка и запуск
Открыть `TouristTrips.pro` в Qt Creator и запустить, либо:
```
qmake TouristTrips.pro
make        # или mingw32-make / nmake
```
