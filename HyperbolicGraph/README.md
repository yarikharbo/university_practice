# HyperbolicGraph — построитель графиков гиперболических функций (Qt)

## Что делает программа
Графическое приложение на **Qt** (Qt Widgets, qmake) для построения графиков гиперболических функций:

- функции **sinh, cosh, tanh**; каждая функция настраивается отдельно: цвет, стиль (сплошная/пунктир/точки), толщина линии, включение/отключение;
- настройка области построения: диапазоны X и Y, размер поля, цвет фона, шрифт и размер подписей, включение сетки;
- интерактивность: **зум** (колесом мыши), **панорамирование** перетаскиванием, контекстное меню, горячие клавиши; текущий видимый диапазон выводится в строку состояния;
- отрисовка выполняется собственным виджетом `PlotWidget` (`paintEvent` + `QPainter`): преобразование мировых координат в пиксельные, сетка, оси, кривые функций;
- папка `tests/` — юнит-тесты виджета на QtTest (`tst_plot`).

## Файлы
- `main.cpp` — точка входа.
- `mainwindow.h/.cpp/.ui` — главное окно с панелью настроек.
- `plotwidget.h/.cpp` — виджет отрисовки графиков (сетка, оси, функции, зум/пан).
- `HyperbolicGraph.pro` — файл проекта qmake.
- `tests/` — тестовый проект QtTest.

## Сборка и запуск
Открыть `HyperbolicGraph.pro` в Qt Creator и запустить, либо:
```
qmake HyperbolicGraph.pro
make        # или mingw32-make / nmake
```
